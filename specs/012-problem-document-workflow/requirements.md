# 012 问题件链路 · 需求规格

## 1. 功能目标

在签收链路完成后，补充审核系统下发问题件的能力。问题件表示理赔申请材料不完整或存在疑问，需要租户补充材料后重新提交审核。

核心能力：
- 审核系统通过 HTTP 回调下发问题件
- 平台记录问题件并更新申请状态为 ISSUE
- 同一申请同一时间只允许一个未关闭问题件
- 支持问题件关闭（租户补材后审核系统确认）
- 问题件关闭后申请状态回退到 WAIT_AUDIT

## 2. 业务规则

### 2.1 问题件下发

- 审核系统调用 `/api/application/v1/callbacks/audit-issues` 下发问题件
- 请求必须包含：`claimApplicationNo`、`issueNo`、`reason`、`auditor`、`issueContent`
- `issueNo` 全局唯一，由审核系统生成
- `reason` 必填，最大 512 字符
- `auditor` 必填，审核人员标识，最大 128 字符
- `issueContent` 为 JSON 格式，记录问题件详情（如缺少的材料清单、疑问说明等）
- 申请必须存在且状态为 WAIT_AUDIT，否则拒绝
- 同一申请已有未关闭问题件时，拒绝下发（数据库唯一约束兜底）
- 下发成功后，申请状态变更为 ISSUE

### 2.2 问题件关闭

- 审核系统调用 `/api/application/v1/callbacks/audit-issues/{issueNo}/close` 关闭问题件
- 请求必须包含：`auditor`（处理人）
- 问题件必须存在且状态为 OPEN
- 关闭后问题件状态变更为 CLOSED，记录 `closedAt`
- 关闭后申请状态回退到 WAIT_AUDIT

### 2.3 幂等性

- 问题件下发：以 `issueNo` 为幂等键，重复下发同一 `issueNo` 返回成功但不重复创建
- 问题件关闭：以 `issueNo` + 当前状态为幂等键，已关闭的问题件重复关闭返回成功但不重复处理
- HTTP 请求头 `X-Request-Id` 用于链路追踪，不参与幂等判断

### 2.4 状态机

申请状态流转：
```
WAIT_AUDIT → ISSUE（下发问题件）
ISSUE → WAIT_AUDIT（关闭问题件）
```

问题件状态：
```
OPEN（未关闭）
CLOSED（已关闭）
```

## 3. 正常场景

1. 签收完成 → 申请状态为 WAIT_AUDIT
2. 审核系统发现材料不完整 → 调用下发接口 → 问题件状态为 OPEN，申请状态变更为 ISSUE
3. 租户补充材料 → 重新提交给审核系统
4. 审核系统确认材料完整 → 调用关闭接口 → 问题件状态变更为 CLOSED，申请状态回退到 WAIT_AUDIT
5. 审核系统继续审核流程

## 4. 异常场景

1. **申请不存在**：下发问题件时申请编号不存在 → 返回 404，错误码 `ISSUE_APPLICATION_NOT_FOUND`
2. **申请状态不匹配**：申请状态不是 WAIT_AUDIT → 返回 400，错误码 `ISSUE_APPLICATION_STATUS_INVALID`
3. **已有未关闭问题件**：同一申请已有 OPEN 状态问题件 → 返回 409，错误码 `ISSUE_ALREADY_OPEN`
4. **问题件不存在**：关闭时问题件编号不存在 → 返回 404，错误码 `ISSUE_NOT_FOUND`
5. **问题件已关闭**：关闭时问题件状态已是 CLOSED → 返回 200（幂等），不重复处理
6. **参数校验失败**：必填字段缺失或超长 → 返回 400，错误码 `ISSUE_INTAKE_INVALID`

## 5. 边界条件

- `issueNo` 最大长度 64 字符
- `reason` 最大长度 512 字符
- `auditor` 最大长度 128 字符
- `issueContent` JSON 大小不超过 64KB
- 同一申请同一时间最多一个 OPEN 状态问题件（数据库唯一约束保证）

### 8.1 问题件下发

- [ ] 审核系统调用下发接口，申请状态为 WAIT_AUDIT 时，问题件创建成功，状态为 OPEN
- [ ] 问题件创建成功后，申请状态变更为 ISSUE
- [ ] 重复下发同一 `issueNo`，返回成功但不重复创建（幂等）
- [ ] 申请不存在时，返回 404，错误码 `ISSUE_APPLICATION_NOT_FOUND`
- [ ] 申请状态不是 WAIT_AUDIT 时，返回 400，错误码 `ISSUE_APPLICATION_STATUS_INVALID`
- [ ] 同一申请已有 OPEN 问题件时，返回 409，错误码 `ISSUE_ALREADY_OPEN`
- [ ] 必填字段缺失时，返回 400，错误码 `ISSUE_INTAKE_INVALID`

### 8.2 问题件关闭

- [ ] 审核系统调用关闭接口，问题件状态为 OPEN 时，问题件关闭成功，状态变更为 CLOSED
